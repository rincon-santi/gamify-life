# Setup & Contributing

## Prerequisites
*   Node.js (v18+)
*   npm

## Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd gamify-life
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

## Development

Start the development server:
```bash
npm run dev
```

Run tests:
```bash
npm test
```

## Building for Production

Build the assets:
```bash
npm run build
```

The output will be in the `dist/` directory.
